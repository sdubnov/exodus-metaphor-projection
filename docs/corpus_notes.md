# Corpus Notes

The historical study used a local corpus that included Exodus, Isaiah Berlin, Surah Al-Qasas, Frederick Douglass, MLK, Herzl, and related materials.

The public reference implementation should not redistribute that whole historical corpus by default. Some texts or translations may have copyright or license restrictions.

Use the included synthetic sample corpus to test the code. For research use, create a local corpus manifest that points to texts you are permitted to analyze.

The hosted GitHub Pages figures were generated from the local Exodus research corpus with passage hover text hidden. The full corpus is not committed to GitHub. See [historical_corpus_workflow.md](historical_corpus_workflow.md) for the exact commands and a local manifest template.
